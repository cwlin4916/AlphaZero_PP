\section{Framing the project}

This project is best situated as \emph{lifted generalized-policy synthesis by
grammar-guided MCTS} --- not as full AlphaZero, at least not yet. The search
machinery is Monte Carlo Tree Search, but it is steered by a grammar over
candidate policies rather than by a value/policy network learned from self-play
over a fixed game; and the object of synthesis is a \emph{lifted} (relational,
object-count-agnostic) generalized policy rather than a tabular or
instance-specific one.

\section{Generalized planning, briefly}

Generalized planning concerns policies or plans that solve \emph{multiple}
instances of a domain --- including the cases where the set of objects and the
set of ground actions change from one instance to the next. This is exactly the
regime a lifted policy is built for: a solution expressed over predicates and
quantified variables, rather than over a frozen ground state space, transfers
across instances with different object sets.
